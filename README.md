# GPU Capstone: Batch Sobel Edge Detection with a CPU vs GPU Study

## Overview

This project applies Sobel edge detection to a batch of 120 grayscale images
on the GPU and compares the performance against a single threaded CPU
reference implementation. Every image is processed by both implementations,
the outputs are verified to be identical, and the log reports per image
timings plus a total speedup number. The main goal is to show, with real
measurements, how a memory bound stencil workload behaves on a GPU versus a
CPU core.

## Code organization

- bin/ : the compiled executable is placed here by make.
- data/input/ : the 120 synthetic input images, regenerated by the script.
- data/output/ : the edge maps produced by the GPU implementation.
- lib/ : reserved for third party libraries, none are needed.
- src/edge_detect.cu : all CUDA and host code in one file.
- src/generate_data.py : regenerates the full dataset in one second.
- Makefile : builds the project with nvcc.
- run.sh : builds if needed, runs the full batch, saves run_log.txt.
- INSTALL : how to set up a machine to build and run this project.

## Requirements

- An NVIDIA GPU with a working driver.
- The CUDA toolkit with nvcc on the PATH.
- A C++11 capable compiler, handled by nvcc.
- Python 3 only if you want to regenerate the dataset.

## Build

    make

## Run

    bash run.sh

## Command line arguments

- -i : input directory that contains .pgm files, default data/input
- -o : output directory for the edge maps, default data/output
- -n : maximum number of images to process, 0 means all files

## Results

run_log.txt contains one line per image with the CPU time, the GPU kernel
time, and a match flag, followed by totals and the overall speedup. The
output images in data/output show the detected edges of the shapes drawn in
the inputs.
